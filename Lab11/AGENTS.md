# Правила проєкту ShowFinder

- Використовуй лише Fetch API та `https://api.tvmaze.com`; не додавай бібліотеки, проксі чи фреймворки.
- Усі запити до API — `GET`. Не додавай `Content-Type` або інші власні заголовки без необхідності.
- Не використовуй `mode: 'no-cors'`, `credentials: 'include'`, `XMLHttpRequest` чи `alert()`.
- Для пошуку використовуй `GET /search/shows?q=...`; перед запитом обрізай пробіли, параметр `q` кодуй через `URLSearchParams`.
- Відповідь пошуку — масив `{ score, show }`. Для `renderResults` передавай масив самих `show` у первісному порядку.
- Менше двох символів — не надсилай запит. Пошук запускається після debounce вводу; Enter запускає його негайно.
- Для серіалу використовуй `/shows/:id?embed[]=episodes&embed[]=cast`, а не запити по одному епізоду чи актору.
- `getShow()` має повертати `{ show, episodes, cast }`; поля `episodes` і `cast` бери з `_embedded`.
- Завжди перевіряй `response.ok`: `fetch` не відхиляє Promise на HTTP 4xx/5xx.
- Читай тіло відповіді один раз і обробляй невалідний JSON як помилку API.
- Перед показом даних перевіряй, що вони мають очікувану форму; не передавай `{ score, show }` замість `show`.
- Скасовуй попередній пошук і завантаження сторінки через `AbortController`; застаріла відповідь не змінює інтерфейс.
- `AbortError` — штатне скасування, не показуй його як помилку та не залишай необроблених Promise.
- Повторюй запит автоматично лише для HTTP 429: один раз після затримки 2–5 секунд.
- Інші помилки автоматично не повторюй; кнопку «Спробувати ще» прив’язуй до того самого запиту.
- Для серіалу кешуй лише успішно завантажений результат. Не кешуй 404, 429, інші HTTP-помилки чи мережеві збої.
- Під час завантаження став `aria-busy="true"` на відповідну область; знімай атрибут після успіху, порожнього результату чи помилки.
- Використовуй надані `#state-loading`, `#state-message` і `#state-error`; не перейменовуй контрактні ID.
- Показуй лише повідомлення з ТЗ: мережа, загальний збій TVmaze, 404 серіалу та 429 мають різні стани.
- Не показуй користувачу `TypeError`, `Failed to fetch`, JSON, коди HTTP чи стек помилки; технічні подробиці залишай у `console.error`.
- Дані додавай на сторінку тільки через `renderResults` і `renderShow` з `src/view.js`.
- Не змінюй `src/view.js`, `check.html`, файли `check/` або `offline.html`.

4. Дослідницькі завдання

4.1. Семантичний HTML та структура документа

Порівняємо нейтральні контейнери з елементами, які називають призначення частин сторінки.

На екрані обидва варіанти можуть виглядати однаково, якщо CSS однаковий. Семантична структура явно передає призначення блоків через HTML-елементи. Вона також дає допоміжним технологіям зрозумілі орієнтири для навігації сторінкою.

4.2. Заголовки та ієрархія контенту

Заголовки мають відображати структуру тем і підтем, а не лише бажаний розмір шрифту.

У структурі H1 → H4 → H2 порушується логічна ієрархія: після основного заголовка одразу з'являється заголовок нижчого рівня, а потім повернення до вищого. Через це структура контенту стає менш зрозумілою для користувача та допоміжних технологій.

4.3. HTML <head> та метадані сторінки

Загальні метадані поступаються опису, який точно називає зміст сторінки.

Другий варіант одразу пояснює, про що сторінка та які плани на ній представлені. Він інформативніший для користувача й пошукової системи.

4.4. SEO-контент: текст, посилання та зображення

Текст посилання має пояснювати призначення переходу, а альтернативний текст — зміст зображення.

Зрозумілий текст посилання

Другий текст точніше пояснює, куди веде посилання, навіть без додаткового контексту.

Описове значення alt

Другий alt точніше описує зображення, тому його зміст зрозуміліший користувачам, які не бачать зображення, та пошуковій системі.

4.5. AI-assisted аудит HTML та SEO

Для аналізу HTML-коду використано AI-асистента. Отримані рекомендації розглянуто з погляду semantic HTML, metadata та базового on-page SEO.

1. Metadata та базовий on-page SEO

Рекомендація 1.1 — заповнити meta description

AI запропонував додати унікальний і змістовний опис сторінки, наприклад:

<meta name="description"
  content="Оберіть тарифний план Basic, Pro або Enterprise. Порівняйте ціни,
  кількість користувачів, сховище та підтримку">

Прийнято: так.

Це дає пошуковій системі короткий опис змісту сторінки. Google може використати meta description для формування опису сторінки в результатах пошуку.

Рекомендація 1.2 — зробити title інформативнішим

AI запропонував замінити загальний заголовок «Тарифні плани» на конкретніший:

<title>Тарифні плани — Basic, Pro, Enterprise | Назва сервісу</title>

Прийнято: так.

Такий title точніше описує сторінку та дає користувачу більше інформації про неї.

Позитивні моменти, відзначені AI
  • lang="uk" на <html> вказує основну мову сторінки.
  • charset і viewport задані коректно.

2. Semantic HTML та мова контенту

Рекомендація 2.1 — узгодити мову контенту

AI звернув увагу, що при lang="uk" частина тексту сторінки написана англійською: назви тарифів, характеристики та кнопки. Запропоновано один із варіантів:

  • перекласти весь текст українською;
  • або позначити англомовні частини атрибутом lang="en".

Прийнято: так.

Це робить мовну структуру однозначнішою та допомагає допоміжним технологіям правильно визначати мову окремих частин контенту.
